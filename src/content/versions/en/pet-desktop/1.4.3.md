> This is an older version. Installed copies update themselves to the newest release; to start fresh, download from the product page.

## Changes

- **Self-update no longer gets blocked by GitHub:** the pet used to ask for new versions through GitHub's API, which allows about 60 requests an hour per IP address. On shared networks (mobile data, school or office Wi-Fi) others often used them up. It now reads the latest release's file list directly.
- **Honest errors:** when a check fails, the tray says "Could not check for updates… try again in a few minutes" instead of wrongly saying you have the latest version.

## If you're on 1.4.0–1.4.2

If the pet says you have the latest version but you don't see this one, download the installer and run it to install over. The pet keeps everything.
