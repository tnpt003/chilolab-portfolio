> This is an older version. Installed copies update themselves to the newest release; to start fresh, download from the product page.

## Changes

- **First run after installing:** a welcome dialog with tips, a language choice, and a **Start with Windows** option.
- Installing while a copied-folder build is running now closes that build so the installed one opens.
- **Settings → General → Updates:** see the version, turn automatic updates on or off, and check for updates.
- After an update, the tray says so; click it to see what's new.
- **Uninstall from inside the app**, with confirmation; the cat's data is removed only if you choose.
- Uninstalling also removes the installed build's Start with Windows entry.
- The installer shows a new waiting screen with a bouncing cat.

The original release notes for this version are in Vietnamese only.
