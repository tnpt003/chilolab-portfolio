## What is this version about?

1.2.2 is a small fix, released the same day as 1.2.1.

## Fixes

- When the crawl pauses for you to choose the next batch or decide on a group of similar pages, **Checking now** shows "—" instead of the previously checked URL. Before, it looked as if the app was still working.

Everything from 1.2.1 (large crawls that stay smooth, restoring a crawl) is included.

## Updating

Installed 1.2.1 copies announce the new version and ask before restarting. The portable build tells you a new version is available; download the new portable file and use it instead of the old one.
