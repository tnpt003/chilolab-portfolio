## What is this version about?

1.2.1 is the first version I have released publicly. It fixes the two most annoying problems with large crawls: from around 300 URLs the app started to freeze, and closing it mid-crawl lost the whole crawl, so no report could be exported.

## Large crawls no longer freeze

- The results table no longer rebuilds itself every time a URL is added. Measured on my machine: 3,000 results used to block the window for about 65 seconds; now it takes about 1 second.
- The table shows the newest 500 rows; the Excel report still contains every result. A new filter searches by URL, page name, status or note, and **Issues only** shows broken pages.
- Faster, steadier crawling: images, fonts and video are not downloaded; page dialogs are dismissed; slow pages time out instead of hanging; the crawler tab is refreshed every 100 pages.
- Checking a long Manual Input list no longer slows down over time.

## Crawls are never lost

- Progress is saved to disk while crawling. After closing the app, a freeze or a crash, the next start offers **Restore** (export or continue) and **Discard**.
- Closing the app during a crawl asks first.
- If the Login Browser is closed mid-crawl, the crawl pauses and can be continued instead of marking every remaining page as broken.

## Other fixes

- Opening the Login Browser for the first time on a slow PC no longer fails after 15 seconds.

## Installing

Get the installer or the portable build on the product page. The app is not code-signed yet, so if Windows SmartScreen warns you, click **More info → Run anyway**. Download file names no longer include the version, so the download button always points to the newest release.
