## What is this version about?

The local source declares version **1.2.0**. Its README and release guide describe Windows distribution and update behavior.

A public 1.2.0 release has not been confirmed. This post documents the local version and distribution plan, rather than announcing a published release.

## Distribution and updates

- Builds produce a portable application and an NSIS installer.
- The portable version checks for updates and opens the Releases page for manual downloads.
- The installed version can download an update and asks before restarting.
- Update notifications are delayed during crawling, manual health checks, or audits.
- Existing 1.1.x portable builds have no updater and need one manual replacement.

## Documented QA workflows

Check manually supplied URLs, crawl a website, and audit Desktop/Mobile URLs with PageSpeed Insights or Lighthouse. Results export to Excel.

These are capabilities documented for the local app, not a claim that every QA feature was introduced in 1.2.0.

## Before updating

Stopped checkpoints are held in memory and lost when the application closes. Export important results before restarting.
